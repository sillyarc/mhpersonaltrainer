1. Visao Geral

Este documento cobre as duas frentes principais do MH Personal Trainer: Web (Next.js) e Mobile (React Native + Expo Router), alem dos servicos de Firebase Cloud Functions.

Objetivo: permitir que qualquer pessoa da equipe entenda rapido como entrar no projeto, como navegar nas paginas, como rodar localmente e onde cada funcionalidade esta no codigo.

Perfis principais suportados no produto: alunopersonal/professoradminacademia
